# Klyroo.Dashboard documentation

The documentation follows the [Diátaxis](https://diataxis.fr/) structure: a tutorial to build your first dashboard, how-to guides for staged loading and filters, reference pages for APIs and platforms, and an explanation of the lifecycle.

## Tutorial

- [Getting started](getting-started.md): install, register, style and build a first dashboard, headless and then in Blazor.

## How-to guides

- [Guides](guides.md): staged loading, filters that reload data, lazy tabs, failures, comparisons, tables, CSV export, timers and tests.

## Reference

- [API reference](api-reference.md): every public type and member, generated from the XML documentation.
- [Platforms](platforms.md): render modes, .NET MAUI (Blazor Hybrid and native views), NativeAOT and trimming.
- [FAQ](faq.md): troubleshooting, known limitations and frequent questions.

## Explanation

- [Concepts](concepts.md): resources and their lifecycle, stages, filters, blocks, re-rendering, culture and design decisions.
