# Lux.Dashboard (LuxStack)

Analytical Dashboard Engine & KPI Blocks for .NET, Blazor, and .NET MAUI:
- **`Lux.Dashboard.Core`**: Headless `DashboardController`, staged async queries (`Essential`, `Background`, `Deferred`), filter controls & presets, view tabs, `DashboardFormat` formatters, comparison date ranges, and UTF-8 BOM CSV export.
- **`Lux.Dashboard`**: Blazor & MAUI Hybrid analytical components (`BxDashboardPage`, `BxDashboardGrid`, `BxDashboardCard`, `BxDashboardStat`, `BxDashboardStats`, `BxDashboardGauge`, `BxDashboardDetails`, `BxDashboardBars`, `BxDashboardList`, `BxDashboardTable`, `BxDashboardAlerts`, `BxDashboardFeed`, `BxDashboardChart`).
